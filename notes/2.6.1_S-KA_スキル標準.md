# 2章 ソフトウェア品質マネジメント — 2.6.1：スキル標準

> 出典 : `/intermediate/syllabus/CH2_intermediate_syllabus.md`

## 🌟 学習目的
スキル標準の考え方や使い方がわかっており、それらを適切に選択して、限られた条件の下で与えられた課題を解決できる。

---

## 🧠 学習対象となる用語，概念
1. **スキル標準**:
    - **定義**: IT人材やソフトウェア開発者の職種、専門分野、スキルレベルなどを体系的に定義した枠組み。
    - **解説**: 個人のスキルを客観的に評価し、キャリアパスを明確にするためのツール。組織にとっては、人材育成計画の策定や、プロジェクトへの適切な人材配置に役立つ。ITSS、ETSS、UISS、iCDなどが代表的。
2. **CCSF**:
    - **定義**: Common Career Skill Frameworkの略。ITSS、ETSS、UISSを統合・再編した、IT分野の共通キャリア・スキルフレームワーク。
    - **解説**: 複数のスキル標準を横断的に参照できるようにすることで、IT人材の多様なキャリア形成を支援する。
3. **ETSS**:
    - **定義**: Embedded Technology Skill Standardの略。組込みソフトウェア開発に特化したスキル標準。
    - **解説**: 自動車、家電、産業機器など、組込みシステム開発に携わる技術者に求められるスキルを定義している。
4. **iCD**:
    - **定義**: IT Capability Developmentの略。企業がITを利活用する上で必要となる能力（人材、組織、プロセス）を可視化し、継続的に強化するためのフレームワーク。
    - **解説**: ITSSやETSSが個人のスキルに焦点を当てるのに対し、iCDは企業全体のIT活用能力に焦点を当てる。人材育成だけでなく、組織変革やビジネス戦略との連携も重視する。
5. **ITSS**:
    - **定義**: IT Skill Standardの略。経済産業省が策定した、ITサービスプロフェッショナルに求められるスキルを体系化した標準。
    - **解説**: IT分野の職種（コンサルタント、プロジェクトマネージャー、ITアーキテクトなど）と、それぞれの職種に求められるスキルレベルを定義している。個人のキャリア形成や、企業のIT人材育成に活用される。
6. **ITSS+**:
    - **定義**: ITSSを拡張し、IoT、AI、ビッグデータなどの先端IT技術に対応したスキル領域を追加したもの。
    - **解説**: 時代の変化に対応し、新たなITスキルを定義することで、IT人材の育成を支援する。
7. **UISS**:
    - **定義**: User Information System Skill Standardの略。情報システムを利用するユーザー企業の情報システム部門に求められるスキル標準。
    - **解説**: ITSSがITサービスを提供する側のスキルを定義するのに対し、UISSはITサービスを利用する側のスキルを定義する。ITベンダーとユーザー企業間のコミュニケーション円滑化にも貢献する。

---

## 📌 頻出論点／出題パターン
- **各スキル標準の対象と目的**: ITSS（ITサービス提供側）、ETSS（組込み）、UISS（ユーザー企業の情報システム部門）、iCD（企業全体のIT活用能力）など、それぞれのスキル標準がどのような対象と目的を持っているかを理解する。
- **スキル標準の活用目的**: 個人のキャリア形成、人材育成計画の策定、適切な人材配置、組織のIT活用能力向上といった活用目的を理解する。
- **CCSFの役割**: 複数のスキル標準を横断的に参照できるようにする共通フレームワークであることを理解する。
