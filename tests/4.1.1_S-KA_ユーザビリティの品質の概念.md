# 4章 専門的なソフトウェア品質の概念と技術 — 4.1.1：ユーザビリティの品質の概念

> 出典 : `/intermediate/syllabus/CH4_intermediate_syllabus.md`

## 🌟 学習目的
ユーザビリティの品質の概念や技術の使い方がわかっており、それらを適切に選択して、限られた条件の下で与えられた課題を解決できる。

---

## 🧠 学習対象となる用語，概念
1. **ユーザビリティの品質の概念**:
    - **定義**: ソフトウェアがユーザーにとってどれだけ使いやすいか、目的を達成しやすいか、満足できるかといった側面を評価するための概念。
    - **解説**: ISO 9241-110で定義される「効果、効率、満足」の3つの側面から評価される。利用時の品質やUXと密接に関連する。
2. **ユーザビリティ**:
    - **定義**: 既出。ISO 9241-110において「特定の利用状況において、特定のユーザーが、ある製品を、特定の目標を達成するために、どの程度効果的に、効率的に、そして満足して用いることができるかの度合い」。
    - **解説**: ソフトウェアの「使いやすさ」を定量的に評価するための概念。単に機能が豊富であるだけでなく、ユーザーがストレスなく、目的を達成できることが重要。
3. **使用性**:
    - **定義**: ISO/IEC 25010の製品品質モデルにおける品質特性の一つ。指定された利用状況において、有効性、効率性、満足性をもって特定の目標を達成するために、特定の利用者が製品を利用できる度合い。
    - **解説**: ユーザビリティとほぼ同義で使われることが多い。分かりやすさ、習得しやすさ、操作しやすさ、エラー防止性、ユーザーインターフェースの快美性、アクセシビリティなどの副特性を持つ。
4. **利用時の品質**:
    - **定義**: 既出。ISO/IEC 25010で定義されている、特定の利用状況において、ユーザーがシステムを利用した結果として得られる品質。
    - **解説**: 有効性、効率性、満足性、リスク回避性、利用状況網羅性の5つの品質特性から構成される。ユーザー視点での品質（UX: User Experience）を評価するモデル。
5. **UX（User eXperience）**:
    - **定義**: User eXperienceの略。ユーザーが製品、システム、サービスを利用する際に得られるあらゆる経験や感情の総体。
    - **解説**: ユーザビリティはUXの一部であり、UXはユーザビリティよりも広範な概念。製品の機能、デザイン、使いやすさだけでなく、ブランドイメージ、サポート、利用環境など、ユーザーが製品と接する全ての側面が含まれる。
6. **魅力的品質**:
    - **定義**: 既出。狩野モデルにおける品質要素の一つ。充足されていなくても不満にはならないが、充足されると大きな満足感や感動を与える品質。
    - **解説**: ユーザビリティの観点では、ユーザーが予期していなかった、嬉しい驚きを与えるような使いやすさやデザインがこれにあたる。他社製品との差別化要因となる。

---

## 📌 頻出論点／出題パターン
- **ユーザビリティ、使用性、利用時の品質、UXの関係**: ユーザビリティと使用性がほぼ同義であり、利用時の品質がそれらを包含する概念、UXが最も広範な概念であることを理解する。
- **ユーザビリティの3要素**: 効果、効率、満足の3要素は頻出。それぞれの意味を理解する。
- **魅力的品質とユーザビリティ**: 魅力的品質が、ユーザーに感動を与えるような使いやすさやデザインに繋がることを理解する。
